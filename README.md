# selenium-language
Работа с языками в Selenium
Инстркцяи по запуску:
1. Создайте новый профиль Firefox, указав при этом папку путь\ к\ файлу/profile,
2. Положите geckodriver в папку с кодом.
3. Запустите команду pytest --language=ваш_язык test_items.py.
Языке должен быть в списке доступеных языков для интернет-магазина.
